commands for path-rep:

{ "addnode" } - Add node to the list. Parameters [character].
{ "addedge" } - Add an edge to the node. Parameters [parent_id, to_id, weight].
{ "clear" } - Clears all node except root. No parameters.
{ "save" } - Save the curent list of vertices locally. No parameters.
{ "reload" } - Reload the node display. No parameters.
{ "vertices" } - Display the vertices in a adjacency list. No parameters.
{ "default" } - Returns the vertices list state back to default(for PPT). No parameters.
